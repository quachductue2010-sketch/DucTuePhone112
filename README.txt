DucTuePhone101 v2

- SwiftUI / iOS 17+
- Chỉ xử lý *101#
- Tab Cuộc gọi: chọn Cách 1 (Viettel) / Cách 2 (Mobifone)
- Tab Danh bạ: nhập SĐT, số tiền, ngày hết hạn
- Cả hai cách đều hiện vòng xoay và "Vui lòng đợi..." trước khi hiện kết quả
- Cách 1 dùng giao diện kết quả Viettel với nút Bỏ qua / Trả lời
- Nút xóa nằm bên phải nút gọi và có kích thước nhỏ
- App icon giữ dấu DEMO

Build IPA trên GitHub:
1. Upload toàn bộ project lên repository.
2. Actions -> Build IPA -> Run workflow.
3. Tải artifact DucTuePhone101-IPA.
